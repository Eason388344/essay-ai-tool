# ✍️ AI写作教练

> 多文体 · 三段式写作助手 | 构思 · 起草 · 修缮

## 🎯 核心功能

| 阶段 | 功能 | 说明 |
|------|------|------|
| **构思破题** | 破题角度 · 提纲搭建 · 素材推荐 | 解决"不知道写什么" |
| **起草扩写** | 关键词扩写 · 风格迁移 | 解决"不知道怎么写" |
| **诊断修缮** | 多维诊断 · 信度校验 · 人机校准 · 闭环验证 | 解决"写得怎么样" |

## 📚 支持文体

- 📊 议论文（高考标准）
- 📖 记叙文（叙事+描写）
- 🌿 散文（意境+语言）

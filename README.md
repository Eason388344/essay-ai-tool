# 📝 AI作文批改研究平台

> 面向高中议论文教学的AI辅助系统 · 信度校验 · 人机协同 · 段落级修缮 · 闭环评价

## 🎯 功能亮点

| 功能 | 说明 |
|------|------|
| **OCR识别** | 上传作文照片自动提取文字 |
| **多维诊断** | 4维度评分（立意/结构/语言/论据） |
| **信度校验** | 3次独立诊断 + 标准差分析 |
| **人机校准** | 教师可修正AI评分偏差 |
| **段落级修缮** | 勾选段落，AI只改指定部分 |
| **范文模仿** | 上传范文，AI模仿其风格 |
| **闭环验证** | 修缮后自动对比前后分数 |
| **Diff对比** | 逐句高亮显示修改内容 |
